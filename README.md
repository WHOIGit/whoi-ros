# WHOI-ROS

ROS 2 drivers, messages and vehicle tools from the Woods Hole Oceanographic Institution.

**This GitHub repository is only a signpost. The code and the docs live on WHOI's GitLab:**

- **Website: <https://whoi-ros.pages.whoi.edu>**, the guide, architecture notes and the
  package index of every public repository
- **Code: <https://git.whoi.edu/whoi-ros>**, the whoi-ros group on git.whoi.edu
- **Wiki: <https://git.whoi.edu/whoi-ros/wr2_docs/-/wikis/home>**, the longer guides,
  including the full getting-started guide and git credential setup

Please open issues and merge requests on git.whoi.edu, not here.

## Getting access

The whoi-ros projects are public to read. To contribute, ask a maintainer of the
[whoi-ros group](https://git.whoi.edu/whoi-ros) for a git.whoi.edu account and project access.
